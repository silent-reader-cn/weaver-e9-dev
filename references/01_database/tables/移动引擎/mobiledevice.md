# 泛微OA 数据表: `mobiledevice`

- **所属模块**: `移动引擎`
- **数据库表名**: `mobiledevice`
- **字段总数**: `6`

## 表结构定义 (Schema)

| 序号 | 列名 (Column) | 中文说明 | 数据类型 | 长度 | 允许为空 | 字段备注 |
| :---: | :--- | :--- | :---: | :---: | :---: | :--- |
| 1 | `id` | 主键列 | `integer` | - | 否 | 主键 |
| 2 | `devicename` | 设备名称 | `varchar2` | 1000 | 是 | 设备名称，mobile：手机，pad：平板 |
| 3 | `picpath` | 图片路径 | `varchar2` | 1024 | 是 | 图片路径，用于定义移动建模自定义页面设计区域的背景图 |
| 4 | `width` | 宽度 | `integer` | - | 是 | 宽度，用于定义移动建模自定义页面设计区域的宽度 |
| 5 | `height` | 高度 | `integer` | - | 是 | 高度，用于定义移动建模自定义页面设计区域的高度 |
| 6 | `defaultenable` | 默认启用 | `integer` | - | 是 | 默认启用：1：默认启用，0：不启用。新建自定义页面会使用默认启用的设备类型作为初始布局 |
