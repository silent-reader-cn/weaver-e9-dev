# 泛微OA 数据表: `social_broadcastreceiver`

- **中文名称**: 存储每条广播的接收人
- **所属模块**: `即时通讯/EMESSAGE`
- **数据库表名**: `social_broadcastreceiver`
- **主键**: `id`
- **字段数**: `3`

> 说明：每条广播有多少接收人，就有几条记录。

## 表结构定义 (Schema)

| 序号 | 列名 (Column) | 中文名称 | 数据类型 | 长度 | 允许为空 | 是否为外键 | 是否自增长 | 外键信息 | 默认值 | 说明 |
| :---: | :--- | :--- | :---: | :---: | :---: | :---: | :---: | :--- | :--- | :--- |
| 1 | `id` | 主键id | `integer` | - | 否 | 否 | 否 | - | - | 主键id |
| 2 | `msgid` | 广播的id | `varchar2` | 400 | 是 | 否 | 否 | - | - | 广播的id（和social_broadcast对应） |
| 3 | `receiverid` | 接收人id | `integer` | - | 是 | 否 | 否 | - | - | 接收人id |
