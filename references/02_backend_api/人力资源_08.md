## 角色设置权限判断

### 请求方式

POST

### 请求地址

/api/hrm/role/getHasRight

### 版本信息

| Ecology版本 | 生效 KB 版本 |
| --- | --- |
| 9.00 | KB900190601 |

### 模块归属

人力资源 > 角色设置权限判断

### 请求参数说明

无特定请求参数（仅需通用请求头认证）。

### 返回值类型

JSON

### 返回示例

```json
{
  "canEdit": true,
  "hasRight": true,
  "status": "1"
}
```

| 字段名 | 类型 | 说明 |
| --- | --- | --- |
| `canEdit` | `Json` | 是否可编辑 |
| `hasRight` | `Bool` | 是否有权限 |
| `status` | `String` | 接口状态 |
