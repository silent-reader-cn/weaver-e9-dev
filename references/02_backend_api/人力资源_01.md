## E7扫码登录

### 概述

**补充说明**：E9扫码登录的时候，手机端点击【登录】，进行PC端登录

### 请求方式

POST

### 请求地址

/api/hrm/login/qrcode/loginQRCode

### 版本信息

| Ecology版本 | 生效 KB 版本 |
| --- | --- |
| 9.00 | KB900190601 |

### 模块归属

人力资源 > E7扫码登录

### 请求参数说明

| 参数名 | 类型 | 必填 | 说明 | 示例值 |
| --- | --- | --- | --- | --- |
| `bizSN` | `String` | 否 | 扩展字段：暂时没有使用 |  |
| `cert` | `String` | 否 | CA相关参数；CA证书：Base64编码。CA扫码的时候使用 |  |
| `isSigned` | `String` | 否 | CA相关参数；是否签名，如果当前请求有CA签名参数，参数值应该是1 |  |
| `loginkey` | `String` | **是** | 二维码标识。唯一标识二维码。PC用此标识来确认登录人员。 |  |
| `randomNumber` | `String` | 否 | CA相关参数；签名原文 |  |
| `signAlg` | `String` | 否 | CA相关参数；算法 |  |
| `signatureValue` | `String` | 否 | CA相关参数；签名值 |  |
| `supportca` | `String` | 否 | CA相关参数；是否进行CA验证。默认为不验证； 1 表示验证。 |  |

### 返回值类型

JSON

### 返回示例

```json
{
  "loginStatus": "1",
  "status": "1"
}
```

### 返回参数说明

| 字段名 | 类型 | 说明 |
| --- | --- | --- |
| `message` | `String` | 失败信息 |
| `status` | `String` | 1： 成功。其他值为失败 |

## 二次验证密码--验证二次验证密码和登录密码是否一样

### 请求方式

POST

### 请求地址

/api/hrm/secondarypwd/checkNewSecondaryPwd

### 版本信息

| Ecology版本 | 生效 KB 版本 |
| --- | --- |
| 9.00 | KB900190601 |

### 模块归属

人力资源 > 二次验证密码--验证二次验证密码和登录密码是否一样

### 请求参数说明

| 参数名 | 类型 | 必填 | 说明 | 示例值 |
| --- | --- | --- | --- | --- |
| `newsecondarypwd1` | `String` | 否 | 密码（设置二次验证密码时） |  |
| `secondarypwd1` | `String` | 否 | 新密码（修改二次验证密码时） |  |

### 返回值类型

JSON

### 返回示例

```json
{
  "result": true,
  "api_status": true
}
```

### 返回参数说明

| 字段名 | 类型 | 说明 |
| --- | --- | --- |
| `api_status` | `Bool` | true-接口正常、false-接口异常 |
| `result` | `Bool` | true-登录密码和二次验证密码一样、false-不一样 |
