## 职务岗位设置--新增岗位

### 请求方式

POST

### 请求地址

/api/hrm/job/addJobTitle

### 版本信息

| Ecology版本 | 生效 KB 版本 |
| --- | --- |
| 9.00 | KB900190601 |

### 模块归属

人力资源 > 职务岗位设置--新增岗位

### 请求参数说明

| 参数名 | 类型 | 必填 | 说明 | 示例值 |
| --- | --- | --- | --- | --- |
| `jobactivityid` | `String` | 否 | 所属职务 |  |
| `jobcompetency` | `String` | 否 | 岗位资格 |  |
| `jobdoc` | `String` | 否 | 相关文档 |  |
| `jobresponsibility` | `String` | 否 | 岗位职责 |  |
| `jobtitlecode` | `String` | 否 | 岗位编号 |  |
| `jobtitlemark` | `String` | 否 | 岗位简称 |  |
| `jobtitlename` | `String` | 否 | 岗位全称 |  |
| `jobtitleremark` | `String` | 否 | 备注 |  |

### 返回值类型

JSON

### 返回示例

```json
{
  "sign": "1",
  "api_status": true,
  "message": "保存成功！"
}
```

### 返回参数说明

| 字段名 | 类型 | 说明 |
| --- | --- | --- |
| `api_status` | `String` | 接口是否存在异常 |
| `message` | `String` | 提示信息 |
| `sign` | `String` | -1：保存失败、1-保存成功 |
