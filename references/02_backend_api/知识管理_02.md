## 新建、编辑文档-附件列表

### 请求方式

GET

### 请求地址

/api/doc/save/getAccListForEdit

### 版本信息

| Ecology版本 | 生效 KB 版本 |
| --- | --- |
| 9.00 | KB900190601 |

### 模块归属

## 新建文档-(取消)收藏目录

### 请求方式

GET

### 请求地址

/api/doc/category/collute

### 版本信息

| Ecology版本 | 生效 KB 版本 |
| --- | --- |
| 9.00 | KB900190601 |

### 模块归属

知识管理 > 新建文档-(取消)收藏目录

### 请求参数说明

| 参数名 | 类型 | 必填 | 说明 | 示例值 |
| --- | --- | --- | --- | --- |
| `operate` | `String` | 否 | 操作类型 | do-搜藏，undo-取消收藏 |
| `secid` | `Int` | 否 | 目录id |  |

### 返回值类型

JSON

### 返回示例

```json
{
  "status": 1
}
```

### 返回参数说明

| 字段名 | 类型 | 说明 |
| --- | --- | --- |
| `status` | `Int` | 是否成功；1-成功，-1-失败 |
