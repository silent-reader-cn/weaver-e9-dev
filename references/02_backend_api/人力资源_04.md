## 权限调整返回结果数据

### 概述

**补充说明**：以下接口涉及动态生成请求参数，建议在oa后台--组织权限中心-—权限管理-—权限调整处，开启F12，操作下具体功能然后查看此接口的请求情况

### 请求方式

POST

### 请求地址

/api/hrm/permissiontoadjust/processData

### 版本信息

| Ecology版本 | 生效 KB 版本 |
| --- | --- |
| 9.00 | KB900190601 |

### 模块归属

人力资源 > 权限调整返回结果数据

### 请求参数说明

| 参数名 | 类型 | 必填 | 说明 | 示例值 |
| --- | --- | --- | --- | --- |
| `authorityTag` | `String` | **是** | 转移/复制/删除分别为transfer/copy/delete |  |
| `fromid` | `String` | **是** | 被转移人id |  |
| `T{key}All` | `String` | **是** | 转移内容的code，是否转移全部。此项为动态参数，根据转移的内容传输，转移多项需增加多个参数。可从 如下sql查询对应功能的code： SELECT CODE_NAME FROM HRM_TRANSFER_SET |  |
| `T{key}AllNum` | `String` | **是** | 转移项需转移的数量，转移数量需从/api/hrm/permissiontoadjust/getPermissionToAdjustList接口获取 |  |
| `toid` | `String` | **是** | 转移到人员id |  |
| `transferType` | `String` | **是** | 转移对象类型，一般为resource |  |

### 返回值类型

JSON
